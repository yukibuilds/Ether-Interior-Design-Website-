# ETHER

## Smart Interior Design & Space Planning Platform

ETHER is a web-based interior design and space planning platform designed to simplify the process of planning and visualizing interior spaces. It provides users with an interactive environment where they can create rooms, arrange furniture, customize designs, and visualize their ideas before making real-world changes.

The platform supports multiple room types, including bedrooms, living rooms, kitchens, dining rooms, study rooms, offices, bathrooms, balconies, home theatres, gyms, kids' rooms, and custom spaces. Users can also create larger projects such as an entire home, duplex, or triplex.

ETHER allows users to design their spaces using an interactive 2D workspace, where furniture can be placed, moved, rotated, and removed. Furniture and room elements can also be customized to create personalized interiors.

The platform includes a 3D visualization system with front, top, and isometric views. Features such as grids, measurements, and cutaway walls help users understand their room layouts and visualize the space from different perspectives.

Budget management is another important feature of ETHER. Users can define their overall and interior budgets while keeping track of furniture costs. Projects can be saved and reopened using browser storage, making it easy to continue working on designs.

ETHER also provides export options, allowing users to export project data as JSON, generate shopping lists in CSV format, and save designs as images.

## Technology

ETHER is built using **HTML, CSS, and JavaScript**, with browser technologies such as **Canvas** for interactive rendering and **Local Storage** for saving projects.

Overall, ETHER brings **planning, customization, visualization, and budgeting** together in one platform, providing a structured and interactive way to transform an empty space into a planned interior.
